# 🤖 AIChat Pro — Smart AI Chatbot

A production-ready AI chatbot with **OpenAI GPT-4**, **RAG (chat with documents)**, and beautiful **Streamlit UI**.

## ✨ Features

- 💬 **Chat with GPT-4** — Real OpenAI API integration
- 📄 **RAG (Chat with Documents)** — Upload PDFs, TXT, MD and ask questions
- 🎭 **AI Personalities** — Python Expert, Data Scientist, Teacher, etc.
- 📚 **Source Citations** — Every RAG answer shows its sources
- 🎨 **Beautiful UI** — Modern chat interface with streaming
- 📥 **Export Chats** — Download conversations as Markdown
- 💾 **Memory** — Remembers conversation context
- 🔄 **New Chat / Clear All** — Easy session management

## 🛠️ Tech Stack

- **LLM:** OpenAI GPT-4o-mini
- **Framework:** LangChain
- **Vector Store:** FAISS
- **Embeddings:** OpenAI text-embedding-3-small
- **PDF Loader:** PyPDF
- **Web UI:** Streamlit
